The earlier archive remains the scientific snapshot. Paths below are relative
to its `audit` directory; no historical code or numerical table was overwritten.
The public package contains maintained operations, not the research scratch
tree, browser captures, source PDFs, plotting assets or experimental records.

Human source adjudication, figure digitization, solid-state labels, original
slurry reference extraction and exposure assignments remain in the separate
scientific resource. They cannot be reconstructed honestly by inventing records
in a code-only repository. Official SC3 and AEM programs remain external and
credited as described in `PROVENANCE.md`.

The eight numerical phase-curve representations use documented exact-temperature
mean handling within one declared form; this is not a claim that forms are
technical replicates. The pooling output uses generic `pooled_x` and `target_x`
names rather than a source-specific isomer name. These interface changes are
listed so a reader can compare the external scientific arrays directly.

Generic safety improvements reject duplicate interpretation identifiers,
noninteger Wilson counts, invalid mode strings and leaked referee fields.
Source-primary provenance references are resolved but unscored by default;
explicitly independent references use the reference role. Evaluation manifests
include prediction-content hashes. These checks do not change valid frozen
scientific inputs or their established outputs.
